# Security

Please report vulnerabilities privately, through GitHub's **Report a vulnerability** button on this repository's
Security tab, not in a public issue.

Especially welcome: a crafted file that makes a parser hang or exhaust memory, a way for parsed data to leave the
machine, an exporter sending data anywhere but the store's own site, or personal data that could slip past the CI
gates. Never include a real statement in a report; describe its structure or use `peek` output.
